# India Rainfall Analysis Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard developed to analyze historical rainfall patterns across India, identify regional and seasonal trends, and explore future rainfall using statistical forecasting.

## Dataset Information
- Historical period: 1901–2015
- Years covered: 115
- Subdivisions analyzed: 36
- Historical records: 4,116

## Dashboard Pages

### Page 1 – Rainfall Overview
- Annual rainfall trend in India
- Average monthly rainfall
- Average seasonal rainfall
- Top 10 rainfall subdivisions
- Bottom 10 rainfall subdivisions

### Page 2 – Regional Rainfall Analysis
- Top 10 subdivisions by average annual rainfall
- Bottom 10 subdivisions by average annual rainfall
- Average annual rainfall comparison across subdivisions

### Page 3 – Rainfall Prediction
- Historical annual rainfall trend
- Power BI statistical forecast
- Forecast target year: 2027
- Forecast limitations and interpretation

**Forecast limitation:** The source dataset ends in 2015. Forecast values beyond 2015 are statistical extrapolations and have not been validated against recent observed rainfall.
